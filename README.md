It is a four-page Metroid-themed portfolio: Home, Projects, About, Contact.

1. HOW TO RUN LOCALLY / LIVE
---------------------------------------------------------------------
The pages are .php files, so open them through a xampp.

- Running locally
1. Download and install xampp v3.3.0 in https://apachefriends.org and run it
2. Make sure you start Apache
3. Download the ZIP files in https://github.com/TCsM23/tcsm-portfolio-final.git  
4. Start Apache in XAMPP
5. Copy the project folder into C:\xampp\htdocs\
6. Open:  http://localhost/tcsm-portfolio-final/

- Running live
1. You need an internet connection
2. type or copy http://yjr-tcsm.site to the browser's search bar

2. VERSION CONTROL (GIT)
---------------------------------------------------------------------
First time, in the project folder:
  git init
  git add .
  git commit -m "Initial commit"
 
Put it on GitHub (create an empty repository there first):
  git branch -M main
  git remote add origin https://github.com/TCsM23/tcsm-portfolio-final.git
  git push -u origin main
 
After each change:
  git add .
  git commit -m "Describe the change"
  git push
